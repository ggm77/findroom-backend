# 빈 강의실 찾기 - findroom

대학교 개설시간표를 바탕으로 특정 시각에 **비어 있는 강의실**을 찾아주는 백엔드 서비스입니다.

수업이 없는 시간에 공부하거나 모일 공간을 찾을 때, 강의실을 하나하나 돌아다니며 확인하지 않아도 되도록 만들었습니다. 요일과 시각(그리고 필요하다면 건물)을 넘기면 그 시점에 비어 있는 강의실 목록을 돌려줍니다.

## 무엇을 하나요

- **빈 강의실 조회** — 요일과 시각을 기준으로 수업이 배정되지 않은 강의실 목록을 반환합니다. 건물을 지정하면 해당 건물만 필터링합니다.
- **강의실 상태 조회** — 특정 건물의 특정 호실이 지금 사용 중인지, 사용 중이라면 어떤 수업(과목명·학수번호·담당 교수)이 진행 중인지 알려줍니다.

## 어떻게 동작하나요

학교에서 내려받은 개설시간표 파일(`.xls` 확장자이지만 실제 내용은 HTML 테이블)을 파싱해, 과목별 강의실·요일·교시 정보를 메모리에 인덱싱해 두고 조회에 응답합니다. 시간표는 학기 중 바뀌지 않으므로 별도의 데이터베이스 없이 서버 기동 시 한 번만 읽어 들입니다.

교시 시간은 1교시 09:00 시작, 수업 75분 + 쉬는 시간 15분을 기준으로 계산합니다. 쉬는 시간에는 직전 교시의 수업이 강의실을 계속 점유하고 있는 것으로 간주하기 때문에, 실제로 들어갈 수 있는 강의실만 "비어 있음"으로 표시됩니다.

## API

| 메서드 | 경로 | 설명 |
| --- | --- | --- |
| `GET` | `/api/v1/emptyrooms` | 주어진 요일·시각에 비어 있는 강의실 목록. `buildingName`으로 건물 필터링 가능 |
| `GET` | `/api/v1/rooms` | 특정 건물·호실의 사용 여부와 진행 중인 수업 정보 |
| `GET` | `/ping` | 헬스 체크 |

요일(`dayOfWeek`)은 월요일이 `0`, 일요일이 `6`입니다. 시각(`time`)은 `HH:MM` 형식으로 전달합니다.

## 기술 스택

FastAPI, Pydantic, lxml
